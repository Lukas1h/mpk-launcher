# MPK Launcher
#### *A fork of https://github.com/osrosal/flauncher.*


MPK Launcher is a modification of FLauncher for AndroidTV-based mobile projector kits.


**Features**

- ⭐ Simplified, fool-proof UI.
- 🔋 Battery percentage indicator.
- 📶 Home screen shortcut for bluetooth settings.
- 💾 Home screen shortcut for external media when inserted.
